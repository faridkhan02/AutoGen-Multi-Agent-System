# AutoGen Multi-Agent System 🤖

## 📌 Project Overview

**AutoGen Multi-Agent System** is a Python-based project exploring AI agents and multi-agent architectures using Microsoft's AutoGen framework and Large Language Models (LLMs).

The repository contains implementations for single-agent workflows, multi-agent collaboration, Gemini integration, multi-message interactions, and agent testing.

The goal is to understand how AI agents can communicate, process tasks, and collaborate to solve problems.

## 🎯 Objectives

- Understand the fundamentals of Agentic AI.
- Build and experiment with single-agent systems.
- Explore multi-agent communication and collaboration.
- Integrate LLMs into agent-based applications.
- Experiment with Gemini-powered AI agents.
- Test and evaluate agent behavior.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **AI Framework:** AutoGen
- **LLMs:** Model integrations depend on the individual implementation.
- **AI Concepts:** AI Agents, Multi-Agent Systems, LLMs, Agent Communication
- **Version Control:** Git and GitHub
